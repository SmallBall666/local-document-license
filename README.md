# 文件授權工具

離線、本機執行的文件加密工具。將文件加密為獨立的 HTML 授權文件，開啟後需輸入產生當日的授權碼，才能下載原始文件。不需要安裝套件、伺服器或部署。

## 使用方式

1. 下載並解壓本專案，在新版 Chrome、Edge 或 Safari 開啟 `index.html`。
2. 選擇原始文件，點選「加密並下載文件」，並保存授權碼與下載的 `.授權文件.html`。
3. 當天開啟授權文件，輸入完整授權碼，即可下載原始文件。

每份文件的授權碼包含本機日期及獨立的隨機資訊；文件透過 AES-256-GCM 加密，金鑰由授權碼經 PBKDF2-SHA-256（210,000 次）推導。全部處理皆在瀏覽器中進行，沒有上傳功能。

## 使用限制

- 原始檔不會自動刪除或加密，請自行妥善保管並留存備份。解鎖後下載的原始檔也不受保護。
- 遺失授權碼或加密檔將無法還原；請妥善保存。
- 日期限制依電腦本機時間判斷。使用者可以透過修改系統時間或程式繞過期限；本工具不適合作為防止蓄意繞過的授權管理系統。
- 加密與解密會將檔案讀入記憶體，大型檔案可能受到瀏覽器記憶體限制。
- 請只開啟可信來源的 HTML 授權文件，HTML 檔案可能包含可執行的程式碼。
